## 2. 一句话定义

本项目是一个面向 Modbus RTU 接口的嵌入式设备的 Windows 上位机，用于完成多设备串口连接（RS485）、实时数据采集与曲线监控、参数物模型定义与配置、报警监控、历史数据查询（SQLite）和 AI 运维助手辅助。

## 3. 背景与目标

### 3.1 背景

工业现场大量设备通过 Modbus RTU 协议接入上位机。不同型号设备的寄存器地址、数据类型、量程各不相同。工程师在现场调试时，需要手动对照寄存器表逐条读写、逐条记录数据，效率低且容易出错。

现有的串口调试工具只做报文收发，不理解数据含义。工程师要自己记住哪个地址是温度、哪个是压力，换一台设备就得重新查表。

更麻烦的是，现场问题排查依赖经验。温度异常是传感器坏了还是管线有问题？压力波动是正常工况还是需要报警？这些问题往往需要资深工程师到场才能判断，而资深工程师不可能 7×24 小时待命。

本项目试图解决这些问题：让上位机理解每台设备的参数模型，自动完成数据采集和存储，并引入 AI 运维助手——工程师用自然语言提问（"温度多少""有哪些报警""压力趋势怎么样"），AI 调用底层工具读取真实设备数据后给出回答。相当于给每台设备配了一个 24 小时在线的运维助手。

### 3.2 目标

- 目标 1：实现串口连接与断开（波特率、数据位、校验位、停止位选择、日志接收与发送，支持 ASCII 和 HEX 双编码收发切换、支持根据输入的 ms 时间勾选自动发送、支持最近 20 条发送命令的保存和查看、支持结尾是否带 \r\n 的选择）
- 目标 2：实现多设备管理，每个设备独立的从站地址和参数物模型定义
- 目标 3：实现对采样参数的曲线趋势查看与分析（1 分钟/10 分钟/1 小时/1 天四档时间范围）
- 目标 4：实现历史数据 SQLite 持久化存储与查询导出
- 目标 5：实现 AI 运维助手，支持自然语言读取设备数据（OpenAI/Anthropic 兼容 LLM）

### 3.3 不做什么

- 本版本不支持：设备控制下发（仅读取）
- 本项目不负责：权限管理（所有用户操作不区分角色）
- 暂不纳入范围：Modbus TCP 协议（仅 RTU）

## 6. 设备与通信

### 6.1 设备清单

| 设备名称 | 型号 | 数量 | 通信方式 | 地址/端口 | 备注 |
| :------: | :--- | :--: | :------- | :-------- | :--- |
| 传感器1 | RDM | 1 | RS485 | COM 口 | 支持多设备 |

### 6.2 通信协议

| 协议       | 用途                       | 关键参数               | 实现状态 |
| :--------- | :------------------------- | :--------------------- | :------- |
| Modbus RTU | 生产环境与工业现场标准协议 | 串口号、波特率、校验位 | ✅ 已实现 |
| 串口控制台  | Console 调试、分析         | HEX/ASCII 收发、行结束符 | ✅ 已实现 |

### 6.3 通信策略

- 连接方式：RS485
- 采集周期：可配置（1 秒/2 秒/10 秒/240 秒，按时间范围档位自动切换）
- 超时时间：100ms
- 重试次数：1
- 批量读取：连续地址参数自动合并为一条 Modbus 请求（间隔 ≤4 寄存器），组间间隔 300ms
- 断线重连策略：无（手动重连）
- 通信异常提示方式：状态栏显示丢包率
- 是否支持离线模拟器：是（串口打开失败自动回退模拟模式）
- 地址格式：支持十进制（1000）和十六进制（0x03E8）

## 7. 点位与数据

### 7.1 参数模型

每个设备独立维护参数列表，参数字段：

| 字段 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| name | str | 是 | 参数名（字母数字下划线，不以数字开头） |
| display | str | 是 | 显示名（中文） |
| address | str | 是 | Modbus 地址（十进制如 1000 或十六进制如 0x03E8） |
| category | str | 是 | 分类（采样参数 / 配置参数） |
| type | str | 是 | 数据类型（uint8/int16/uint16/int32/uint32/float32/bool） |
| access | str | 是 | 访问权限（只读 / 只写 / 读写） |
| curve | str | 否 | 是否参与趋势曲线（是/否，默认否） |
| unit | str | 是 | 单位 |
| decimals | int | 否 | 小数位数（默认 0） |
| min | str | 否 | 最小值（选填） |
| max | str | 否 | 最大值（选填） |
| desc | str | 否 | 说明（选填） |

参数表持久化到 `config/params.json`，按设备 ID 分组存储。

### 7.2 数据刷新要求

- 实时数据刷新频率：1 秒（默认，可调）
- 趋势图刷新频率：与实时数据同步
- 历史数据写入频率：每次采样自动写入 SQLite
- 最大点位数量：无限制（UI 自动滚动）
- 数据异常时显示规则：metric 卡显示 `--`，通信失败不追加曲线

### 7.3 数据存储

| 数据类型 | 存储方式 | 存储路径 | 导出格式 | 保留策略 |
| :------- | :------- | :------- | :------- | :------- |
| 采样数据 | SQLite | save/history.db | CSV | 不自动清理 |
| 报警记录 | 内存 | — | CSV | 重启不丢（默认数据） |
| 发送历史 | JSON | config/send_history.json | — | 最近 20 条 |
| 串口日志 | TXT | history/*.txt | TXT | 超 10MB 自动保存 |
| 参数配置 | JSON | config/params.json | — | 手动编辑持久化 |
| 设备配置 | JSON | config/devices.json | — | 手动编辑持久化 |
| 策略配置 | JSON | config/policy.json | — | 手动编辑持久化 |
| 模型配置 | JSON | config/model_config.json | — | 手动编辑持久化（含 API Key，不提交 git） |

## 8. 功能需求

### 8.1 设备管理 ✅

- 多设备管理：每设备独立参数表和从站地址
- 设备 CRUD：新增/编辑/删除设备（持久化到 devices.json）
- 设备切换：参数配置页和监控页支持设备下拉切换

### 8.2 串口连接 ✅

- 串口参数配置（串口号/波特率/数据位/校验位/停止位）
- 连接/断开/刷新串口
- 真实串口 + 模拟回退（无设备时自动模拟）
- 控制台三 Tab：串口原始日志 / 通信统计 / 诊断日志
- HEX/ASCII 显示切换
- 手动发送：HEX/ASCII + 行结束符 + 自动发送 + 发送历史
- 串口日志超 10MB 自动保存 TXT
- 立即保存 / 打开本地保存目录

### 8.3 实时监控 ✅

- 实时点位 metric 卡（动态等于采样参数，2 列网格，整体滚动）
- 短周期趋势曲线（QtCharts，支持 1 分/10 分/1 小时/1 天四档）
- 曲线筛选 chip（点击显隐，颜色固定不漂移）
- 暂停/继续采样（默认暂停，用户点"开始采样"才启动）
- 清除曲线
- 单曲线时 Y 轴显示参数名称和单位
- 时间轴显示 HH:mm:ss（或 HH:mm）
- 后台线程轮询（QThread），UI 不卡

### 8.4 参数配置 ✅

- 参数表 11 列（复选框/参数名/显示名/地址/分类/类型/权限/单位/小数/范围/说明）
- CRUD：新增/编辑/删除参数
- 上移/下移调整顺序
- 分类筛选（全部/采样参数/配置参数）
- 校验：名称唯一、地址唯一（同设备内）、地址格式（十进制/十六进制）
- "曲线展示"字段控制是否参与趋势曲线
- 设备切换下拉框
- 持久化到 params.json

### 8.5 报警管理 ✅

- 报警表 7 列（复选框/时间/内容/终端/级别/状态/确认信息）
- 确认状态机：单条确认/全部确认（不可逆，已确认 checkbox disabled）
- 全选 checkbox（仅未确认行）
- 计数联动 tag（侧边栏标签同步未确认数）
- CSV 导出

### 8.6 历史数据 ✅

- 时间范围查询：快捷按钮（近1小时/近6小时/近24小时/近7天/自定义）
- 点位多选下拉（CheckableComboBox）
- 趋势曲线渲染（QtCharts）
- CSV 导出

### 8.7 设备总览 ✅

- 4 metric 卡（当前串口/在线设备数/当前告警数/离线阈值）
- 4 快捷操作卡（点击跳转对应页面）
- 设备列表表格（名称/从站地址/参数数量/设备位置/描述/状态）
- 动态联动串口连接状态

### 8.8 状态策略 ✅

- 离线判定配置（启用/超时/单位/范围）
- 状态转换预览表（超时值联动更新）
- 持久化到 policy.json

### 8.9 系统设置 ✅

- 软件信息键值表（名称/版本/平台/运行时长）
- 维护操作键值表（保存路径/日志空间/配置文件/帧错误计数）

### 8.10 AI 运维助手 ✅

- 对话 UI（用户气泡 + 助手气泡 + 工具卡片 + 思考动画）
- 真实 LLM 调用（后台线程，支持 OpenAI 兼容 + Anthropic 兼容）

- 对话历史保留（切页不丢）

### 8.11 模型配置 ✅
