# AI 编程质量门禁与常见坑-上位机

此文件为[quality-gates-and-pitfalls.md](quality-gates-and-pitfalls.md)子集的上位机项目门禁，当系统提示词或 Agent 规则为上位机相关时，查看此文件内容。

#### 目录

* 上位机重点测试项目
* 上位机硬约束

#### 1、上位机重点测试项目

1. 考虑协议解析是否正确
2. 考虑断线重连是否稳定
3. 考虑设备超时是否可控
4. 考虑控制命令是否有确认、权限和互锁
5. 考虑报警是否不会漏报、误清除
6. 考虑配置文件错误时是否能明确报错
7. 考虑没有真实设备时，模拟器是否能跑完整流程
8. 考虑打包后的程序是否能在目标机器运行

#### 2、上位机硬约束

1. 禁止在 UI 层直接访问串口、TCP、PLC 或数据库
1. 禁止跳过设备模拟器测试
1. 禁止把真实设备 IP、密码、Token 写进代码
1. 所有协议变更必须同步 docs/protocol-spec.md
1. 所有点位变更必须同步 docs/device-matrix.md
1. 所有控制命令必须有确认逻辑和失败处理
1. 涉及设备写入的代码必须有单元测试或模拟器验证
1. 打包发布前必须运行 make test
