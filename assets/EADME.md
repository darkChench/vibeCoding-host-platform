# ? Assets

本目录只存放静态资产与外部资源入口，不再承载知识库、技能库、提示词库或外部仓库源码。

| 目录          | 用途                                       |
| :------------ | :----------------------------------------- |
| `images/`   | 上位机相关文档图片、截图、封面、html等资产 |
| `README.md` | 外部资源入口                               |
| `AGENTS.md` | 本目录维护规则                             |

## 与仓库文档的关系

- 核心知识库位于 `docs/`。
- 上位机工程位于 `vibe-hmi/`。
- 记忆库位于`meory-bank/`。
- 提示词库入口位于 `prompts/`。
- 技能库位于 `skills/`。
- 外部工具、子模块与本地配置位于 `tools/`。
